# Semiconductor Yield Variance Analytics & Financial Reporting

An enterprise analytics project combining SQL ETL data modeling, yield variance analysis, and financial revenue impact tracking across silicon manufacturing lots.

---

## 📌 Business Overview
In semiconductor manufacturing, minor yield drops directly translate to millions in unrecovered costs. This project models production lot performance against target baseline yields to quantify revenue variance and isolate critical manufacturing bottlenecks.

## 🛠️ Key Features
* **SQL ETL Pipeline:** Structured data schema for tracking lot-level wafer parameters.
* **Variance Analytics:** Calculates target vs. actual yield variances and projected revenue impacts.
* **Executive KPI Reporting:** Isolates high-risk production lots requiring immediate engineering intervention.
